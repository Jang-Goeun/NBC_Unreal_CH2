## 📌 과제1(MyProject) 프로젝트 개요
언리얼 엔진의 가장 기본 단위인 `Actor`를 생성하고, C++ 코드를 통해 3D 공간에서의 좌표 이동, 회전 및 로직 흐름을 제어하는 실습을 진행했습니다.
- **목표**: 언리얼 엔진 C++ 환경에서의 액터 제어 및 디버깅 능력 배양
- **주요 학습 내용**:
  - `AActor` 클래스 상속 
  - 3D 좌표(`FVector`)와 회전(`FRotator`) 시스템 이해
  - `AddOnScreenDebugMessage`를 이용한 실시간 로그 디버깅
  - `FMath` 라이브러리를 활용한 확률 로직 구현

---

### 🛠 Tech Stack
- **Engine**: Unreal Engine 5.7.4
- **Language**: C++
- **IDE**: Visual Studio 2022

---

### 🚀 주요 구현 기능

#### 1️⃣ 필수 구현 (기초 환경 및 로직)
- [x] **Actor 클래스 및 외형 설정**: C++ 클래스 생성 및 StaticMesh(Cube)를 활용한 액터 시각화
- [x] **초기 위치 설정**: 시작 시 위치를 `(0, 0, 50)`으로 고정
- [x] **Move & Turn 함수**: 
  - `Move()`: 현재 좌표에서 특정 거리만큼 이동하는 로직 구현
  - `Turn()`: 특정 각도만큼 회전하는 로직 구현
- [x] **랜덤 반복 실행**: 총 10회 동안 무작위 이동 및 회전 로직 수행
- [x] **실시간 로그 출력**: `AddOnScreenDebugMessage`를 사용하여 이동 시마다 현재 좌표를 화면에 표시

#### 2️⃣ 도전 구현 (심화 로직)
- [x] **상태 정보 고도화**: 이동 횟수(Step)를 좌표와 함께 실시간 출력
- [x] **50% 확률 이벤트 시스템**: `FMath::FRand`를 활용하여 각 스텝마다 50% 확률로 특정 이벤트(`TriggerEvent`) 발생
- [x] **최종 리포트 생성**:
  - `FVector::Dist`를 활용한 전체 누적 이동 거리 계산
  - 10회 종료 후 **총 이동 거리** 및 **이벤트 발생 횟수**를 요약하여 출력

### 📝 학습 및 트러블 슈팅
- **로그 출력**: `UE_LOG`는 출력 로그 창에 남지만, `AddOnScreenDebugMessage`는 실시간 게임 화면에서 바로 수치를 확인할 수 있어 즉각적인 피드백을 받는 데 유리함을 학습했습니다.
- **벡터 연산**: `FVector` 간의 거리 계산 시 직접 구현하는 대신 엔진 내장 함수인 `FVector::Dist`를 활용하여 효율성을 높였습니다.
